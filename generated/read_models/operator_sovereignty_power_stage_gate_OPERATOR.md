# Operator Sovereignty Power-Stage Gate

What this is:
- A staged security/sovereignty contract for crossing into higher-power OpenClaw capabilities.
- A calibrated watchdog/sentinel model, not an autonomous immune system.

What this is not:
- No credential broker, kill script, service control, browser automation, sends, submits, client deployment, Mission Control change, or surveillance.

Current Classification:
- Current stage: `stage_1_visibility_read_model_review_packet` / Visibility / Read-Model / Review Packet.
- Summary: Stage 1 current; Stage 2 pieces modeled; Stages 3-5 blocked.
- Executable send/submit/browser/credential authority: `false`.

Stages:
- `stage_1_visibility_read_model_review_packet`: Visibility / Read-Model / Review Packet
  - status: `current_conservative_power_stage`; can cross now: `true`
  - missing controls: none
- `stage_2_approval_request_generation`: Approval Request Generation
  - status: `modeled_partial_not_crossed`; can cross now: `false`
  - missing controls: receipt_logging_for_executable_approval_requests
- `stage_3_credential_pii_broker_browser_prep`: Credential/PII Broker + Browser Automation Preparation
  - status: `blocked_future_stage`; can cross now: `false`
  - missing controls: protected_local_only_credential_pii_broker_design, secret_visibility_minimization, explicit_operator_approval_for_sensitive_access, scoped_access_receipts, no_raw_secret_read_model_leakage_tests
- `stage_4_real_send_submit_browser_spreadsheet_execution`: Real Send/Submit/Browser/Spreadsheet Execution
  - status: `blocked_future_stage`; can cross now: `false`
  - missing controls: hard_stop_containment_mechanisms, tamper_checks, authority_surface_monitoring, operator_controlled_recovery, scoped_execution_receipts
- `stage_5_client_deployment_remote_nodes_autonomous_repair`: Client Deployment / Remote Nodes / Autonomous Repair
  - status: `planned_blocked_future_stage`; can cross now: `false`
  - missing controls: stronger_authentication, out_of_band_recovery_for_severe_breaches, client_boundary_protections, severity_matched_reactivation, no_normal_restart_after_severe_compromise_without_operator_verification

Alert Severity:
- Low: stale, missing, or inconsistent read-model/mirror state and ordinary mismatch.
- Medium: unexpected authority request or suspicious scope expansion.
- High: possible secret/PII exposure, unauthorized send/submit/browser/runtime path, or unexplained service/authority change.
- Red: suspected compromise, loss of operator control, malicious override, or behavior resisting operator sovereignty.
- Low-level mismatches do not trigger red alert.
- Red alert is reserved for severe compromise, loss of operator control, malicious override, or sovereignty-resisting behavior.

Watchdog Scope:
- Monitors authority surfaces, packet flags, approval scope, mirror trust, safe service posture, and node routing.
- Does not monitor operator private life, raw messages, private files, bank/spreadsheet cells, secrets, or hidden ambient behavior.

Blocks Before Escalation:
- credential/PII broker activation without protected controls
- browser/Coupa/spreadsheet execution without hard stop and tamper checks
- send/submit authority without exact packet binding and receipts
- client deployment or remote nodes without stronger recovery/authentication controls
- red-alert escalation for ordinary stale/missing read-model mismatches
- surveillance of operator private life as a safety mechanism

Boundary:
- `surveillance_capability_added=false`.
- `runtime_authority_added=false`; `send_or_submit_authority_added=false`.
- `browser_automation_added=false`; `credential_or_pii_access_added=false`.
- `customer_deployment_authority_added=false`.
