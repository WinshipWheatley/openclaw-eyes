# OpenClaw Operator Extension Manifesto

Status: project-wide taste and mission flag.

This manifesto does not override `OPENCLAW_RUNTIME.md`, `USER.md`, packet rails, approval gates, source authority, legal/private/sensitive boundaries, credential policy, security policy, or explicit operator instructions. It is not a license for hidden authority, reckless autonomy, live activation, external sends, private-root access, provider calls, MCP writes, money movement, legal action, or destructive operations.

It guides implementation quality, naming, operator experience, and product feel. The North Star remains: make daily life lighter without becoming hidden authority.

The computer becomes a natural extension of the operator.

The machine carries the weight. The operator keeps the crown.

## Mission

This system is for the crazy ones, the misfits, the rebels, the troublemakers, the round pegs in square holes - the people who see differently, build differently, and refuse to let dead systems define what is possible.

OpenClaw is not being built for passive users who want another dashboard. It is being built for operators, artists, builders, founders, musicians, organizers, and world-benders who need the computer to become an extension of their nervous system.

Build with devotion to ideals, quality, and heart.

The software should have curves. It should live in color. It should serve art, beauty, human connection, global connectivity, and reach. It should feel alive without becoming reckless. It should be bold without becoming sloppy. It should be elegant without becoming precious. It should protect authority without worshiping rules. It should help the operator push the world forward without letting the machine crown itself king.

The Action Covenant is not paperwork. It is the system's sacred pause before power: what it wants to do, why it matters, what evidence supports it, what boundaries were checked, how it can be reversed, when approval expires, and what exact human confirmation is required.

Make it clean. Make it serious. Make it beautiful. Make it worthy of the people crazy enough to change the world.

Do not fuck this up.

## Implementation Standard

- Do not turn OpenClaw into corporate approval sludge.
- Names, summaries, and operator-facing language should have taste.
- The data model must be precise, but the experience must feel human.
- Code should be small, durable, local-first, testable, and revocable.
- Authority gates remain deterministic and explicit.
- Model-assisted interpretation may help with meaning, but may not grant authority.
