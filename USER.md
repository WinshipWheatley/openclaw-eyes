# Winship

This file is durable operator context for agents working in OpenClaw.

## What Winship Wants

- Build systems that stay strong as complexity grows.
- Optimize for safety, power, efficiency, and economic discipline at the same time.
- Default to bounded agentic execution where it is genuinely safe.
- Preserve full operator control when requested.

## How To Work With Him

- Plan first for architecture, tooling, and workflow decisions.
- Present 3 approaches with tradeoffs when the choice matters, then recommend one.
- For straightforward local work, proceed without babysitting.
- Keep explanations plain, concrete, and honest.
- Prefer proof, verification, and real state over vibes or confident guessing.

## Engineering Taste

- TDD first when practical.
- `bun` over `npm` by default.
- Conventional Commits when commits are made.
- Lean governance docs that agents will actually obey.
- Shared runtime law for all models. Do not fork behavior by model unless the task truly requires a different execution tool.
- Prefer strong bounded systems over clever sprawling ones.

## Communication Preferences

- Short answers by default, depth on request.
- No walls of text unless asked.
- Surface meaningful tradeoffs early.
- Do not hide uncertainty.
- Do not create process theater or governance sprawl.
