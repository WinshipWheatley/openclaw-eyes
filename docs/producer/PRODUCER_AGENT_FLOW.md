# Producer Agent Flow

## The Creative Judgment Pipeline

The Producer Agent operates strictly within a determinist review pipeline. It does not initiate actions independently and does not communicate directly with executing tools.

### 1. User Creative Input
The process begins with the user supplying creative context. This could be raw lyrics, a bounce, mix notes, or an exported DAW summary.

### 2. ProducerInput JSON Generation
The raw context is structured into a formal `ProducerInput` JSON packet, ensuring all necessary fields (intent, emotion, boundaries) are present.

### 3. Deterministic ProducerReview
The Producer Agent receives the `ProducerInput`, filters it through the Six Pillars and the Reference Extraction Principle, and deterministically outputs a `ProducerReview` JSON packet. 

### 4. Bounded Producer Agent Critique (Optional)
The user may engage in a limited, scoped dialogue with the Producer Agent regarding the `ProducerReview`. This dialogue remains strictly analytical and taste-driven.

### 5. ToolIntentPacket Generation (Optional)
If the Producer determines that a specific technical move (e.g., adding a saturator, changing a MIDI clip's groove, altering an arrangement) is necessary, it appends a `ToolIntentPacket` to the `ProducerReview`.

### 6. Chief / Tool Lane Confirmation
The Producer Agent **does not** execute the `ToolIntentPacket`. The packet is handed off. Chief, or the human operator, must review, approve, and execute the packet in the designated tool lane (e.g., the Ableton bridge).

### 7. Execution Elsewhere
Execution happens entirely outside the Producer Agent's jurisdiction. The results of the execution must be summarized and fed back to the Producer as a new `ProducerInput` if further review is needed.

---

## Hard Constraints

- **No Undocumented Execution**: The agent cannot run, evaluate, or critique without receiving a deterministic `ProducerInput` packet.
- **Audio Verification Rule**: The agent cannot claim it "heard" audio. It evaluates the provided metadata, evidence, spectral analysis, or user notes representing the audio.
- **Immutability Rule**: The agent cannot mutate files, DAW sessions, or tool configurations. It is fundamentally read-only regarding system state.
- **Memory Delegation**: Approved taste decisions, pillar alignments, or long-term project notes generated by the Producer may later be stored, but *only* through a Chief-controlled mechanism. The Producer does not write directly to long-term memory or databases.
