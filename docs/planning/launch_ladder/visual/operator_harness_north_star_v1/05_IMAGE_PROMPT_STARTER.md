# Image Prompt Starter

Use this prompt in a new visual brainstorming chat after the packet has been loaded.

```text
Do not generate an image first.

Read the Operator Harness / Mission Control visual packet and begin by proposing 6-8 distinct visual directions. Each direction should preserve the North Star: high-trust, calm late-night command room, studio-console discipline, Mac-native restraint, evidence-backed workflow control, human authority, local-first sensitivity, no chatbot slop, no generic SaaS dashboard, and no fake autonomy theater.

Include the Winship Operator Ship direction as a first-class option. Treat the operator as captain and the app as a navigable vessel/world looking out over an Annapolis-inspired marina or future coastal port. Explore contextual floating widgets over a window view, one small VU/signal/evidence meter, and modes such as Bridge, Helm, Chart Room, Engine Room, Cargo Hold, Radio Room, Treasury/Purser's Office, Studio Bay, and Ports.

Do not treat the ship as a literal game, pirate theme, naval/military command center, luxury yacht ad, spaceship, or gimmicky nautical interface.

For each direction, include:
- scene composition
- window-into-the-world concept
- VU/signal meter concept
- color and material language
- what Operator Harness state it communicates
- what to avoid

Then recommend the top 2 directions and explain why.

Do not write final image-generation prompts until the operator chooses a direction.
```

Winship Operator Ship starter:

```text
Before generating images, brainstorm the Winship Operator Ship metaphor for Operator Harness / Mission Control.

The operator is the captain. The app is a serious navigable vessel/world, personal and elegant, looking out over a hopeful Annapolis-inspired marina or future port at night. The main surface is a window into the world, not a dashboard grid. Contextual floating widgets appear over the view when needed and disappear when handled. A single small VU/signal/evidence meter shows live pulse, evidence strength, or watch state.

Propose several coherent visual treatments for this direction and recommend the two strongest before writing image prompts.
```
