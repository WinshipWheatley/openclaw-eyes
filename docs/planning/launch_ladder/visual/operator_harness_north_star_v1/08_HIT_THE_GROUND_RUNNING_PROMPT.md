# Hit The Ground Running Prompt

Use this after the new chat has passed the mission/metaphor audit and the operator has chosen one direction to explore.

```text
The mission/metaphor audit passed. Start with the Operator Ship concept and produce the first refined image-generation prompt only for the selected direction.

Work one direction at a time. Do not overbuild.

Before the image prompt, give a short coherence check:
- how the operator is captain
- what part of the vessel/world is visible
- what the window looks out onto
- which contextual widgets appear
- what the single VU/signal/evidence meter communicates
- what authority boundary is preserved

Then write:
1. One primary image prompt.
2. Two useful variations.
3. A short negative prompt / avoid list.
4. Composition notes for what must be visible.
5. Trust/safety notes for what must not be implied.

Keep the prompt focused on North Star imagery:
- high-trust Operator Harness / Mission Control
- Winship Operator Ship
- operator as captain
- app as navigable vessel/world
- Annapolis-inspired marina or future port
- calm late-night coastal command view
- Mac-native restraint
- evidence-backed workflow control
- human authority
- local-first / sensitive-aware cues
- contextual floating widgets
- one small VU/signal/evidence meter

Do not create final app UI.
Do not use readable UI text, product names, logos, private data, robots, anime, floating assistant faces, hologram nonsense, generic SaaS dashboards, military/naval command centers, spaceships, literal game UI, pirate themes, gimmicky ship wheels, luxury yacht ads, dystopian ports, or fake autonomy vibes.

After the first prompt set, stop and wait for operator feedback before producing another direction.
```
