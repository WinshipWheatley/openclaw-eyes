# Hard Avoids

Avoid these unless the operator explicitly changes scope:

- cyberpunk overload
- spaceship cockpit
- military command center
- car/truck cockpit
- generic corporate dashboard
- readable UI text
- logos/product names
- hologram nonsense
- robots
- anime
- overdesigned sci-fi
- clutter
- AI assistant face floating on a screen
- fake autonomy vibes
- pirate theme
- military/naval command center
- spaceship
- literal game UI
- gimmicky ship wheel
- nautical cliche overload
- luxury yacht ad vibe
- dystopian port
- dashboard grid as the main concept

Additional caution:

- Do not imply that the AI has hidden authority.
- Do not make the interface feel like surveillance.
- Do not include real financial, legal, medical, client, or personal data.
- Do not use screenshots or UI text that could be mistaken for a real product commitment.
- Do not make visual polish substitute for evidence, state, approval, or safety.
