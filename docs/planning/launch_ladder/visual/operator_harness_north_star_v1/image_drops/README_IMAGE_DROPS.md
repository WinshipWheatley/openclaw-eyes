# Image Drops

This folder is for manually copied ChatGPT-generated visual references.

Do not place private/sensitive images here.

Use descriptive filenames, for example:

- `01_watch_window_marina.png`
- `02_operator_ship_bridge.png`
- `03_helm_widgets.png`

Images are visual prior art / taste reference only, not implementation authority.

Future design docs should cite the image filename and the reason it matters.

Do not include raw financial/legal/private screenshots here.

Boundaries:

- No sensitive finance, legal, client, medical, tax, credential, private-message, or personal-document screenshots.
- No raw app/runtime screenshots unless explicitly sanitized and approved for design reference.
- No images here should be treated as final UI, product commitment, or authority over evidence/state/approval doctrine.
