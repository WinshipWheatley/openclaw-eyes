# Breadcrumb For Operator Harness

This packet is a reusable visual-taste capture pattern for Operator Harness / Mission Control work.

It now includes the Winship Operator Ship visual metaphor: the operator as captain, the app as a navigable vessel/world, and modes organized around Bridge, Helm, Chart Room, Engine Room, Cargo Hold, Radio Room, Treasury/Purser's Office, Studio Bay, and Ports.

It also now includes the Spatial Operator World Model: Dock / Land, Ship, Ports, Offices / Client Sites, rooms, and transit as future spatial representations of authority scopes and work contexts. That model should feed future navigation/modeling docs and real-world mental model training, not implementation directly.

It should feed later taste, atmosphere, and design doctrine documents. It should not feed implementation directly.

Boundary:

This packet does not decide final UI, authorize app implementation, authorize runtime behavior, authorize agent behavior, or override evidence/state/approval doctrine.

The best use is as a taste compass: compact enough to travel, precise enough to keep future visual chats from drifting into generic AI assistant imagery.
