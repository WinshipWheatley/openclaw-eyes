# Current Visual References

Known reference direction:

A refined studio-control-room console image with blue/violet monitor glow, amber status lights, dark glass, brushed metal, city-at-night atmosphere, and quiet evidence of an operator being present: notebook, coffee, chair, keyboard, or hand-written notes.

The scene should feel like late-night professional work. It should not feel like a promo render, a hacker cave, a spaceship cockpit, or a generic enterprise dashboard.

New Operator Ship direction:

An Annapolis-inspired marina / yacht-club future view: calm water, warm dock lights, restrained boats, coastal glass, subtle city/harbor glow, and a personal command environment that feels lived-in but not cluttered. It should feel hopeful and local, not dystopian or generic.

The main screen should feel like a window looking out into the world. Contextual widgets can float over that window when they are needed: current command, next safe action, evidence pulse, source freshness, approval, or a blocked state. When widgets appear, the marina/world background may soften slightly; when idle, the background can be sharp, calm, and present.

Jarvis / Earl inspiration:

- The key idea is a "window into the world" that gives place, motion, and presence.
- The world-window should make the system feel connected to reality without becoming surveillance theater.
- Pair that world-window with a VU-meter-like signal box or evidence signal meter.
- The meter should communicate listening, confidence, evidence strength, state change, or watch activity.
- Translate the insight into a Bridge / Captain's View: a living window over a port, route, workflow, or active context.
- Keep one small VU/signal meter as a live system/evidence pulse, not a wall of gauges.

Translate the Earl-style reference carefully:

- keep: embedded interface, world-view presence, tactile monitor cluster, useful signal meter
- discard: car/truck cockpit aesthetics
- discard: redneck-Jarvis framing
- discard: novelty dashboard culture
- discard: loud persona-first UI

The desired translation is studio-born Mission Control: an operator-grade room with a window into active work, evidence, and state.

Move away from physical monitor/console duplication. The operator already has a real 4K monitor, keyboard, mouse, Ableton Push, APC40, drives, and studio hardware. The visual direction should not merely draw another literal desk full of screens. It should create a product world that lives inside the app: a navigable vessel, view, and set of temporary operational widgets.
