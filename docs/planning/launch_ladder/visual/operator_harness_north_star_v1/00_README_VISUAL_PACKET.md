# Operator Harness North Star Visual Packet

Purpose:

This packet captures visual taste, atmosphere, and direction for Operator Harness / Mission Control imagery. It is meant to be loaded into a new ChatGPT Project or chat before any image generation, UI design, or implementation work begins.

Use this packet to brainstorm visual directions for a high-trust operator console: local-first, evidence-backed, calm, human-authoritative, and free of generic chatbot or SaaS dashboard assumptions.

How to use:

1. Upload or paste the packet into a new visual brainstorming chat.
2. Start with `07_FINAL_HANDOFF_PROMPT.md`.
3. Ask the chat to audit the mission and propose visual directions before writing image prompts.
4. After the mission audit passes, use `08_HIT_THE_GROUND_RUNNING_PROMPT.md`.
5. Generate or refine image prompts only after the operator chooses a direction.

Instruction for the new chat:

Execute the handoff. Do not merely reformat this packet. Read the visual thesis, identify tensions or missing choices, then propose practical visual directions that preserve trust, restraint, and operator authority.

Boundaries:

- This packet is not implementation authority.
- This packet does not decide final app UI.
- This packet does not authorize runtime, services, agents, approvals, queues, data mutation, ingestion, or provider/model behavior.
- This packet is for taste capture, visual exploration, and future design documentation only.
