# Core Visual Motifs

Use these motifs as recurring visual vocabulary. They should support trust and orientation, not become decoration.

- window into the world
- VU meter / signal meter / evidence signal meter
- studio console
- night city / exterior environment
- source/evidence cards
- approval / next safe action card
- local-first protected data cues
- calm Mac-native interface
- tactile controls
- amber + blue/violet glow
- notebook/coffee/human operator presence
- captain's view / bridge window
- marina / port / boats / future Annapolis
- contextual temporary widgets
- one small VU/signal meter
- routes / ports / navigation as workflow metaphor
- local-first protected zones as charted waters / restricted holds
- calm water / future horizon / warm dock lights

Motif notes:

Window into the world:
Shows the outside context, active workflow, monitored environment, or state of the mission. It gives place and motion without implying unauthorized surveillance.

VU / signal meter:
Shows system attention, evidence strength, workflow health, confidence with reasons, or mode activity. It should feel closer to a studio meter than a sci-fi scanner.

Studio console:
Gives tactile discipline: channels, routing, status strips, controls, meters, and recall. It should be restrained and functional.

Evidence cards:
Represent claims tied to source references. They should feel inspectable and calm, not like social-media cards or sales dashboards.

Approval card:
The human authority moment. It should be clear, grounded, and consequence-aware.

Local-first cues:
Small cues that data is local, protected, staged, or sensitive-aware. Avoid padlock cliches when possible.

Captain's view:
The main ambient surface. It looks outward over a port, route, context, or horizon. It communicates that the operator is at the helm, not trapped inside a dashboard grid.

Contextual widgets:
Temporary floating surfaces for decisions, evidence, command, approval, blocked states, and next safe actions. They should appear when needed and disappear when handled.

Ports and routes:
Use navigation as a workflow metaphor. Ports can represent clients, companies, projects, domains, or life contexts. Routes can represent workflow paths, launch packets, evidence chains, or active missions.

Restricted holds / charted waters:
Use maritime structure to signal local-first and sensitive-aware boundaries. Protected zones should feel inspectable and deliberate, not scary.
