# Mac-to-PC Import Planning: Operator Harness

This directory contains the documentation-only import plan for migrating Operator Harness materials from the Mac environment (`OpenClaw_Watch`) to this PC WSL repository.

## Core Principles

1. **Docs-Only Planning**: This phase is strictly for mapping and prioritization. No files have been imported during the creation of these documents.
2. **Canonical Authority**: The PC WSL repository remains the canonical source of truth. Mac-side materials are "candidate materials" and are not authoritative by default.
3. **Surgical Import**: Future imports will be performed surgically, mapping specific source candidates to verified repo destinations.
4. **Security & Privacy**: Strict boundaries are maintained. No sensitive, financial, or private materials from the Mac environment are authorized for import.

## Directory Structure

- `01_MAC_SOURCE_CANDIDATE_MAP.md`: Inventory of candidate materials on the Mac.
- `02_PC_DESTINATION_MAP.md`: Proposed destinations within the PC repository.
- `03_IMPORT_PRIORITY_AND_SEQUENCE.md`: The recommended order of operations for future imports.
- `04_DO_NOT_IMPORT_BOUNDARIES.md`: Explicit list of excluded files and directories.
- `05_LEDGER_INVOICE_STEEL_THREAD_CANDIDATE.md`: Status and plan for the first functional proof-of-concept.
- `06_HANDOFF_PROMPT_FOR_ACTUAL_IMPORT.md`: Prepared prompt for executing the actual import phase.
