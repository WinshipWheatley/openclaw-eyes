# Do-Not-Import Boundaries

The following materials are strictly excluded from the import process. This list is non-exhaustive and any material of a similar nature must also be excluded.

## Excluded Paths
- `LOCAL_ONLY_RAW_DO_NOT_UPLOAD/`
- `law_program/`
- `.claude/`
- `secrets/`
- `vaults/`
- Any paths containing personal, financial, or legal data.

## Excluded Material Types
- **Raw Screenshots**: Only processed/necessary visual documentation is permitted.
- **Financial Data**: Bank exports, CSVs with real transaction data, or financial ledgers.
- **Private Content**: Any personal communications, client material, or private notes.
- **Sensitive Files**: `Google Contract.md`, `cassandra_forensic_audit.md`, or similar audit/contractual documents.
- **Binaries/Executables**: Only source code and documentation.
- **Credentials**: Provider configurations, API tokens, or keys.

## Enforcement
Any attempt to import these materials will be treated as a violation of security protocols. The PC repo must remain clean of all raw, local-only, and sensitive data from the Mac environment.
