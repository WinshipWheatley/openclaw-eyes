# OpenClaw Lane A OpenRouter Scout Backlog

## Purpose

OpenRouter may be useful later as a Lane A cloud model scout / cheap subagent overflow layer for public/synthetic work, especially when Copilot/Codex credits are expensive or when model comparison is useful.

This is a backlog/design note only. It is not an instruction to use OpenRouter now, and it is not a core OpenClaw routing change.

## Not Now

Do not wire OpenRouter into OpenClaw yet.

Do not add API keys.

Do not add runtime routing.

Do not add autonomous access.

## Allowed Future Use

Only consider OpenRouter for:

- public docs
- synthetic fixtures
- non-private architecture opinions
- model/paper evaluation
- cheap critic passes
- non-sensitive planning drafts
- model scouting before local adoption

## Forbidden Use

Never use OpenRouter for:

- Legal real matter / Lane B
- private vault contents
- Gmail body/private correspondence
- secrets/API keys
- support packets unless sanitized/public-safe
- client identities or client documents
- personal legal facts
- anything not safe to paste into a cloud model

## Operating Model

Recommended future shape:

- manual first
- advisory only
- output not canonical until reviewed locally
- no automatic commits
- no direct access to repo/private files
- no autonomous routing
- hard Lane A/Lane B separation

## When To Revisit

Revisit only after current audit/lockdown lanes settle and if one of these appears:

- Copilot/Codex credit pressure
- need for many cheap subagent reports
- model comparison/scouting work
- public/synthetic benchmark analysis
- non-private document review workload

## Possible Future Artifact

A future prompt template or tiny wrapper could be created, but only after policy review. It should have a visible header:

> Lane A only. Public/synthetic only. Not canonical. Review before use.

## Relation To Ollama And LM Studio

Ollama remains the local/private default.

LM Studio is an optional local model lab.

OpenRouter is only a possible cloud scout/overflow option for non-private Lane A work.
